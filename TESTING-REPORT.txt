                    AUDIOMANAGER API OVERVIEW
================================================================================

Initialization:
  • initialize(): Promise<void>
    - Async Tone.js setup
    - Browser autoplay policy handling
    - Creates Player and Sampler

Music Playback:
  • playMusic(): void
  • pauseMusic(): void
  • stopMusic(): void
  • loadMusicTrack(trackId: string): Promise<void>
  • seekMusic(position: number): void
  • getCurrentPosition(): number
  • isPlaying(): boolean

Volume Control:
  • setVolume(channel: VolumeChannel, value: number): void
    - Supports: 'master', 'music', 'sfx'
    - Clamped to 0-1 range
    - Automatic dB conversion
  • toggleMute(): void

SFX Playback:
  • playSFX(type: SFXType, options?: SFXOptions): void
    - 500ms debounce per type
    - Optional volume/pitch control

Settings Management:
  • saveSettings(): void
  • loadSettings(): AudioSettings
  • getSettings(): AudioSettings

Lifecycle:
  • dispose(): void
    - Cleanup resources
    - Reset state
