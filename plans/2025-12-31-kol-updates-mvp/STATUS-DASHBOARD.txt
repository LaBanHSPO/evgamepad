DEDUPLICATION STRATEGY
────────────────────────────────────────────────────────────────────────────

Hash Method:    MD5 of (kol_id + timestamp + message_text)
Collision Risk: Virtually impossible
DB Enforcement: UNIQUE constraint on message_hash

Detection Flow:
  1. Webhook received
  2. Calculate MD5 hash
  3. Check if hash exists in DB
  4. If exists → return deduplicated=true
  5. If new → INSERT + broadcast
